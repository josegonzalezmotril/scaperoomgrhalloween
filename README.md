# La Noche de los Candiles

Escape room 3D ambientado en un carmen granadino durante Halloween.

## Jugar en local

Abre `index.html` en un navegador moderno con conexión a Internet. El juego carga Three.js desde `esm.sh`, así que no necesita instalación ni proceso de compilación.

## Controles

- Flechas o `WASD`: moverse.
- `E`: investigar un objeto cercano.
- Botón `Pista`: consultar una pista de la sala.
- En móvil: usar los controles táctiles.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y este `README.md` a la rama principal.
3. En **Settings > Pages**, selecciona **Deploy from a branch**.
4. Elige la rama principal y la carpeta `/root`.
5. Guarda y abre la URL que GitHub Pages muestre.

El juego es estático y no necesita servidor propio. La conexión a Internet sólo se usa para cargar Three.js y la imagen de portada.

## Recorrido

1. Resuelve la sucesión de la carta para conseguir la llave.
2. Ordena los cuatro símbolos del mosaico para revelar la pista de la Alhambra.
3. Introduce `1492` en la cerradura de la cámara secreta.
